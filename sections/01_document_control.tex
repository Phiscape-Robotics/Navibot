\subsection{Executive Abstract}
NaviBot is planned around a Raspberry Pi 4B, LiDAR, camera, and two Arduino motor-controller nodes, each controlling two motors. The project owner has confirmed that the Pi will communicate with both Arduinos over a shared RS-485 bus using a UART-to-RS-485 converter. ROS 2 Lyrical Luth on Ubuntu 26.04 arm64 is the proposed Pi software platform. The software architecture, ROS node responsibilities, control data flow, and candidate bus protocol are described in Section 6. The current architecture diagram predates this update and still shows one Arduino and a direct UART link. Matching Arduino firmware, exact components, navigation behavior, and hardware validation remain to be completed. The project purpose and the network-discovery utility's relationship to the robot also remain to be confirmed.
