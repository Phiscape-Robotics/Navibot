\subsection{Executive Abstract}
The repository contains an initial NaviBot electronics block diagram and a Python utility for best-effort discovery of IPv4 devices on a local Wi-Fi/LAN. The diagram depicts a Raspberry Pi 4B, LiDAR, camera, Arduino, motor driver, four encoder-equipped DC motors, and a battery with a regulator/power module. The project purpose, runtime behavior, exact component specifications, and relationship of the network utility to the robot remain to be confirmed. This draft provides a structured place to document those items and identify design and validation work; it does not establish that the illustrated system has been built or tested.
