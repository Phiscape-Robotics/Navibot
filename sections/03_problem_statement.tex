The engineering problem has not yet been supplied. Define the task NaviBot must perform, the environment and users it serves, and the current limitation the design is intended to address. The project name and component diagram alone do not establish these requirements.

\subsection{Known Design Inputs}
The repository diagram depicts an 11.1 V nominal Li-ion battery, Raspberry Pi 4B, LiDAR, camera, one Arduino, an L298N dual H-bridge, and four DC motors with encoders. The project owner has clarified that the intended control system has two Arduinos, each controlling two motors, connected to the Pi on a shared RS-485 bus. The diagram does not yet reflect that update. Component models, motor-driver allocation, transceivers, ratings, compatibility, and realized configuration require confirmation.
