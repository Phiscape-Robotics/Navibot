Architecture status: the current block diagram is an earlier revision and shows
one Arduino with a direct UART link. The confirmed project architecture uses
two Arduino motor-controller nodes on a shared RS-485 bus. Update the Draw.io
source and exported image together before treating this figure as current.

Keep editable draw.io diagram source files here, for example:
- block_diagram.drawio
- circuit_diagram.drawio

LaTeX does not render .drawio files directly. Export each diagram from draw.io
to PDF, PNG, or JPG in this same folder. The template includes the exported
image when it has one of the expected names below.

Required project figures:
1. block_diagram.png (or .pdf/.jpg)
2. circuit_diagram.png (or .pdf/.jpg)

If you use another filename, update the matching image path in
sections/05_methodology.tex.

Recommended:
- Prefer PDF for vector diagrams; PNG and JPG exports are also supported.
- Use PNG for exported diagrams/screenshots.
- Keep text large enough to remain readable at 90–95% page width.
